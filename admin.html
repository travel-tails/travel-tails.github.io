Veličina i položaj (fino)

Naslov tačno na sredini, uvek isto od gornje ivice i bar 1 cm od bočnih ivica. Isključi samo ako dizajn traži položaj iz Figme.

Ovaj dizajn ima tekst kao deo slike: može da se objavi, sakrije ili premesti, ali se tekst ne pomera.

Novi dizajn

Čim izabereš sliku vidiš kako korica izgleda. Posle dodavanja možeš još da pomeraš naslov i sliku u uređivanju.

U Figmi izaberi okvir korice (A4) → desni klik → Copy/Paste as → Copy link to selection. Ilustracija, naslov i godina se prenose tačno kao u Figmi, a kupac i dalje može da menja naslov i godinu.

Potreban je samo jednom: Figma → Settings → Security → Personal access tokens → Generate new token (dozvola „File content: Read only“). Čuva se samo u ovom pretraživaču.

Automatska objava

Kad je ovo podešeno, „Objavi na sajt“ sam menja sajt (bez preuzimanja i prevlačenja fajlova). Radi se samo jednom.

  1. Otvori github.com → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. Repository access: samo travel-tails.github.io. Permissions: Contents → Read and write.
  3. Kopiraj token i nalepi ga ovde. Čuva se samo u ovom pretraživaču.
